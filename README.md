# pointbreak

A real-time model of a peeling surf wave — specifically the Pleasure Point
right-hander in Santa Cruz — built as a *zipper*: a breakpoint traveling along a
wave crest, generated by narrow-band swell meeting an angled shelf.

Not a fluid simulation. A **reading** of a wave: the three relations that make a
point break peel (shoaling, refraction, break criterion), reduced to a kinematic
form cheap enough to run in a fragment shader, expressive enough that locals
recognize the spot.

## The idea

- **One master knob** — the shelf's tilt against the swell sets the peel angle,
  which spans the whole local taxonomy: Cowell's (slow, mellow) → Jack's →
  Pleasure Point → The Hook → The Slot (fast, barreling).
- **One special event** — Middle Peak's A-frame: a shallow bump instead of a tilted
  plane, two zippers firing outward in mirror symmetry.
- **Sets for free** — two beating spectral components give wave groups (~5–7 waves,
  minutes-scale rhythm) with no extra machinery.
- **"Today's ocean"** — CDIP buoy spectra can drive the model with the actual swell
  running outside.

## Layout

- `docs/MODEL.md` — the vehicle-independent parametrization (start here)
- `docs/research/` — CDIP live data, surf-science citations, TD implementation recon
- `glsl/zipper.md` — shader-ready form of the break layer
- `td/` — TouchDesigner build (via tdmcp), composites the zipper over an FFT ocean substrate
- `web/` — raymarched reference build (cliff + drone views, slider panel, live CDIP fetch)
- `web-three/` — three.js displaced-grid build (the surfer lives here; see below)

## web-three

The second web vehicle: the same model rendered as a displaced triangle grid
(three.js) instead of a raymarched heightfield. The model GLSL is shared —
`web/js/model-glsl.js` is spliced into both renderers, so the two builds
cannot drift apart. On top of the shared model, web-three adds choppy
horizontal displacement (the lip visibly pitches when ξ says plunging) and a
procedural surfer riding the zipper line with a follow camera.

Run it (no build step, plain ES modules):

```
cd pointbreak
python3 -m http.server 8000
# open http://localhost:8000/web-three/   (or /web/ for the raymarcher)
```

Keys: `1`–`7` spot presets, `V` camera (Free / Cliff / Drone / Follow),
`S` surfer, `space` pause, `H` hide panel. Spec: `docs/WEB_THREE_SPEC.md`.

## Vehicles
